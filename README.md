# sosa-homelab
 Documentation and infrastructure notes for my self-hosted Ubuntu server ecosystem.
 ## Core services:
| Service | Purpose |
|---|---|
| Jellyfin | Media streaming |
| Seerr | Media requests |
| Glance | Dashboard |
| Uptime Kuma | Monitoring |
| Komga | Manga/comics |
## Hardware
### Main Server
- Dell OptiPlex 3050 SFF
- Ubuntu Linux
- 256GB SSD
- 4TB Seagate Enterprise HDD
### Workstation
- ASUS ROG Zephyrus G14 (2021)
- Used for administration and testing
### Networking
- Cloudflare Tunnels & Domain Management
- Local Docker-based service infrastructure
