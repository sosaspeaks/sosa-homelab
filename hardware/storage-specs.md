# Storage Devices

## Primary Media Storage

### 4TB Seagate Enterprise HDD
- Capacity: 4TB
- Usage:
  - Jellyfin library
  - Komga library
  - General long-term storage
- Mounted on Ubuntu Linux server
- Used as the primary storage volume for self-hosted services
- Enterprise-grade HDD selected for high-capacity media storage and long-duration uptime reliability

## Operating System Drive (256GB SSD)
- Ubuntu Linux installation drive
- Hosts Docker containers, configurations, and service data

## Storage Goals
- Reliable long-term media storage
- Centralized self-hosted content access
- Expandable infrastructure for future services and backups, such as DAS or NAS
